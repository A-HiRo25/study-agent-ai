#Application Overview

・AI Tutor: Using LLMs, users can interactively communicate with AI and it provides job hunting strategies and learning tips based on users personal information.

・RAG: Using RAG, AI can make an answer more precisely by getting information from syllabus and Canvas calendar feed.

・Task Management: Based on .ics file and syllabus (+ additional information from users), it can create todos not to miss any deadlines and an important event for job-hunting. TODOs are stored in SQLite.

・Canvas Calendar Integration: Reading .ics file, the application can see coursework schedules and deadlines, and it can add schedules to googln calendar.

・Web Application: This application works at one place, meaning UI can be very simple, and also everyone can use this application through URL.
